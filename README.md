# Focusly

Focusly is a simple productivity app to help you plan, track, and finish what matters.  
It combines tasks, habits, and lightweight insights so you can stay consistent without feeling overwhelmed.

**What you can do**
- Create and organize tasks
- Track progress and streaks
- See your stats at a glance
- Manage your profile and settings

**How the project is organized**
- Web app built with a modern React-based framework
- API routes for app features
- Auth and user data handled securely

**Getting started**
- Install dependencies
- Add your environment settings
- Run the app locally

**Quality checks**
- Linting and type checks
- Security and environment validation

**Support**
If you run into issues, open an issue or message the team with:
- What you were trying to do
- What you expected to happen
- What actually happened
